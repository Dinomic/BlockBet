BlockBet · Auth flow

Login, sign-up and a Home placeholder. Try the live phone (type, toggle the eye, submit), then scan the state gallery below. Hint for the fake server: taken@blockbet.io already exists on sign-up; password wrong fails on login.

What happens in the live phone

  • Validation runs on submit, then clears per field as you type.
  • Server call shows a spinner for about 1.2 s and disables the form.
  • Server failures show a banner above the form, not inside a field.
  • Sign-in success opens Home; Log out returns to Login.
